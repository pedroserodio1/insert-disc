# ADR-0020: Nome do projeto: Insert Disc

**Status:** aceito; resolve a [Q1](../OPEN-QUESTIONS.md#q1-nome)

## Contexto
O nome "Disc Console" era provisório. Alternativas consideradas: Discoteca, Gaveta, Jewelcase, Spin Up, Jogoteca, Spindle, Encarte, Lombada, Disc Two, Cakebox, Bandeja.

## Decisão
**Insert Disc**: a mensagem clássica dos consoles ("Please insert disc"), que é exatamente o que o app pede. O nome é o mesmo em pt-BR e en.

## Consequências
- Busca feita em 2026-09-28: nenhum projeto de launcher com esse nome no GitHub (só um fórum pequeno, sem relação). Projetos com proposta parecida estão em [VISION](../VISION.md#projetos-relacionados).
- Verificar disponibilidade da organização/repositório no GitHub e de nomes de pacote na hora de publicar.
